# Full-Stack Developer Knowledge Base Index

Welcome to the **Full-Stack Developer Knowledge Base** — a comprehensive, "Zero to Hero" learning curriculum containing over **1,500 structured dictionary terms** across 15 core web development, framework, database, and systems technologies.

---

## 🗺️ Learning Roadmap & Curriculum Phases

The curriculum is organized progressively from fundamental building blocks to production-grade architecture and high-performance systems programming:

| Phase | Category / Domain | Modules Included | Key Focus Areas |
| :--- | :--- | :--- | :--- |
| **Phase 1** | **Web Fundamentals** | [`01-html`](./01-html/), [`02-css`](./02-css/), [`03-javascript`](./03-javascript/) | Markup semantics, layout & styling, core JS language & DOM |
| **Phase 2** | **Connecting to the Web** | [`04-apis`](./04-apis/), [`05-nodejs`](./05-nodejs/) | HTTP/REST, async protocols, server runtime & modules |
| **Phase 3** | **Frontend Frameworks** | [`06-react`](./06-react/), [`07-vue`](./07-vue/) | Component architecture, state management, reactivity |
| **Phase 4** | **Type Safety & Scale** | [`08-typescript`](./08-typescript/) | Static typing, generics, interfaces, compiler config |
| **Phase 5** | **Modern Meta-Frameworks** | [`09-nextjs`](./09-nextjs/), [`10-nuxtjs`](./10-nuxtjs/) | Full-stack SSR, App Router, file-based routing, server engine |
| **Phase 6** | **Quality Assurance** | [`11-automated-testing`](./11-automated-testing/) | Unit, integration, E2E testing, TDD methodology |
| **Phase 7** | **Data Persistence & DBs** | [`12-postgres`](./12-postgres/), [`13-mongodb`](./13-mongodb/), [`14-surrealdb`](./14-surrealdb/) | SQL, Relational, Document-NoSQL, and Multi-Model Graph databases |
| **Phase 8** | **Systems Programming** | [`15-rust`](./15-rust/) | Memory safety, ownership, concurrency, high-performance systems |

## 🏗️ Standardized Module Architecture

Each technology folder adheres to a unified internal folder structure to ensure consistent document layout and ease of navigation:

```text
knowledge-base/{technology-folder}/
├── _meta/
│   ├── technology_context.md          # Technology-specific persona, rules & guidelines
│   └── {tech}_terms_zero_to_hero.md   # Master roadmap listing terms level by level
├── missing_{tech}_terms_ai_knowledge_base.md  # Tracking missing terms / backlog (optional)
└── terms/
    ├── level_01/                       # Beginner level terms
    ├── level_02/                       # Intermediate level terms
    └── ... level_NN/                   # Advanced level terms
```
